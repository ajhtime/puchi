# ぷちぷち

スマホで遊ぶ、ぷちぷちだけのページです。

https://ajhtime.github.io/puchi/

## 遊び方

1. 泡を指で押すと、その場ですぐにつぶれます。音を出しているときは音も、振動をオンにしているときは振動も、押した瞬間にいっしょに届きます。
2. 「丸」と「ハート」で、泡のかたちを選べます。
3. 音は最初、消えています。大きなスピーカーのボタンで音を出して、となりのつまみで大きさを変えられます。
4. 「振動」で、振動のオンとオフを切り替えられます。iPhone では、振動が届かないことがあります。
5. 全部つぶせたら、「もう一回」で、もう一度はじめから遊べます。
6. ブラウザのメニューから「ホーム画面に追加」すると、アプリのように開けます。

## LINE で送る文例

ぷちぷちで遊べるよ。
丸とハート、すきなほうをそっとつぶしてみて。
https://ajhtime.github.io/puchi/
